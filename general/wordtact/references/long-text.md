# Long text: scoped brief, source lookup and joins

Use complete paragraphs, argument units or scenes as working windows. Read enough adjoining
text to understand conditions and referents. Do not cut through a quotation, conditional,
exception or cross-paragraph exchange to hit a fixed character budget.

## Carry a small, sourced brief

Keep only what matters now: target range; original version/path; applicable author rules;
stable terms and definitions; selected approved sample and its scope; local exceptions and
unresolved dependencies. Omit empty fields. Briefs point back to sources rather than becoming
a second authority. Distinguish an explicit author choice from your sample-based observation.

An example, not required project state:

```text
Target: discussion §3.2; Chinese academic prose; source path/version as supplied
Rule: preserve association rather than assert causation
Dependencies: low-light definition in methods §2.1; missing-data rule in §2.3
Local limits: possible effect; outdoor validation not yet done
Approved voice sample: location and scope if one exists
```

## Work and resume

1. At each window, consult the applicable brief near the material being edited. Read the
   source for exact numbers, quotations, definitions and any distant relation used in a change.
2. Edit only the target window; adjacent material is context, not automatically authorized
   for revision. Make one candidate and check the real difference against the original.
3. Expand lookup when a relation crosses the boundary. Never guess a definition or drop a
   qualifier because its source is distant. If the source is unavailable, retain the uncertain
   wording or report the limited scope; do not certify the whole manuscript.
4. Check the joins: pronouns, tense/time, terminology, repeated explanations and section
   function. Compare equivalent speakers/registers rather than averaging the whole document.
5. On resumption, re-establish source version and applicable author decisions. A changed
   file or newly accepted paragraph is not automatically an approved new style baseline.

Re-use the host's working record or keep a task-local brief; do not require a new project
directory. Loading fewer references reduces extra context, but does not remove existing chat
history. If the host offers context compaction or a clean continuation, carry a recoverable
brief with source locations; it is not a substitute for originals or proof of independent review.
