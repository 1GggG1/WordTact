# 中文小说中的 Humanizer 补充检查

与[共用语言规则](anti-ai-patterns.md)一起使用。这里补通用清单中尚未明确的表达问题；
定语、嵌套关系和主干负担仍由[中文阅读负担](../../novel-auditor/references/reading-load-zh.md)
维护，声音按[文风约定](../../novel-auditor/references/style-consistency.md)的适用范围判断。
这些检查不增加失败次数线，不改变已有整章计数、证据边界或 CI 验收。

| 现象 | 复核与最小处理 | 小说中应保留的情形 |
|---|---|---|
| 空泛铺垫、伪深刻格言、无对象的辩护 | 找到真正主张或需要纠正的理解；只删无作用的外壳，不替含混比喻猜新论点 | 不可靠叙述、人物自我辩护、讽刺、犹疑、必要定场与故意回环 |
| 拔高、宣传语、句尾赞美 | 检查是否重复已经呈现的判断，是否偷加作者未提供的意义 | 人物的偏见、激动、宣传演说、文内广告及叙述者有意的态度 |
| 模糊关联与借权威 | 原文有明确关系时可直说；保住谁声称、谁相信及证据边界 | 谣言、引述、未证实判断和隐藏身份；不补专家，不把人物相信的事改成叙述事实 |
| 限定堆叠与复杂系动词 | 同一层不确定性可合并，不同条件分别保留；核对能力、计划与完成状态 | “仅在……时可能”“尚未查明”可同时必需；“超过”不改成“等于” |
| 生造标签与名词堆叠 | 没有新增含义的标签可用已有动作或定义表达 | 世界观术语、制度名、人物行话及稳定称谓，不轮换近义词去重 |
| 助手或草稿残留 | 检查成稿中是否混入对用户的解释、夸奖、邀请和修订说明 | 人物安慰、信件礼貌、档案修订记录与有故事作用的写作过程 |
| 装饰性排版、标题复述 | 只在授权范围调整无用强调；遵守现有标点与文件保护规则 | 书信、档案、引文、章节题目、特殊排版与有用结构，不直接套网页排版偏好 |

这些类别与已有排比、否定辨析、碎片和重复检查合并出条目，不重复审一遍或重复扣分。
强行要求每句新增事实会抹掉节奏与情绪；“语法没错”也不能替无功能的堆叠免责。

例：“城门在午后开放，标志着所有矛盾已彻底消失。”若原稿事实只支持开门，后半句需
回查叙述依据，不能顺手当成事实。如果人物说“门一开，什么麻烦都没了”，它可能是在
逞强或误判，应保留人物立场，不能润色成可靠的全知说明。

润色已有小说不因“fiction”而自动获得添加动作、情绪和细节的授权。扩写任务按其已有
创作范围执行；审稿则核对实际差异中的主体、否定、条件、归因、时间与完成状态，再读
相邻段落。发现来源不明的实质断言时标明疑点，不擅自删除情节或补全真相。

来源改编与许可见 [Humanizer 通知](../THIRD_PARTY_NOTICES.md)。
