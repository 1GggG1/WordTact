# 叙事呈现工作台

本文件负责把已经确定的故事规格落实为读者可经历的叙事。它不决定正典，不替代
`scene_card`，也不负责 AI 痕迹审计。句式、词频和段落表面问题仍由
`anti-ai-patterns.md` 处理。

## 使用方式

先判断当前材料需要哪些模块，只加载相关部分：

| 场景信号 | 必看模块 |
|---|---|
| 重点细节、悬念线索、感官密集 | 1. 细节是证据 |
| 跨时段、重复劳动、旅行、例会、蒙太奇 | 2. 叙事时间分配 |
| 动作很多但局面不变、关键发现、重大决定 | 3. 行动—发现—回应 |
| 对话主导、谈判、试探、隐瞒、闲聊 | 4. 对话是行动 |
| 特殊文体、心理距离、背景描写、信息边界 | 5. 视角与背景 |
| 反复物件、意象、主题、章末回看 | 6. 物件与主题纪律 |

`budget: full` 时，写前做最低预检，写后按“叙事呈现 → 表层规则”两轮检查。
`budget: scene` 时，答案来自 `scene_card`；生成完成后直接交给 `novel-ci` review，
不在生成阶段自行判分或修稿。

以下判断都服从更高优先级约束：`scene_card` / 项目正典与风格配置 / 用户明确意图。
本文件不设感官数量、比喻数量、对话比例或冲突强度的固定配额。

## 1. 细节是证据

细节的价值不在“写得丰富”，而在让读者据此推断。重点细节至少承担一种功能：

- 改变人物下一步行动；
- 暴露人物的专业、偏见、欲望、恐惧或社会位置；
- 建立压力、危险、时代或阶层条件；
- 为稍后的发现、误解、决定或物件变化提供证据；
- 调整叙事速度或注意力焦点。

### 写前问题

1. 读者看到这个细节后，可以多推断出什么？
2. 为什么是当前 POV 注意到它，而不是另一个人物？
3. 如果删掉它，行动、判断、压力或后续追踪是否受损？

### 操作程序

1. 先确定本段需要读者得出的推断。
2. 选择能被当前人物真实感知的证据。
3. 把证据放进动作或判断发生的位置，不另开“展示环境”的陈列段。
4. 延后解释；只补读者完成当前理解所必需的信息。
5. 重读时删除功能重复的细节，保留彼此产生新信息的细节。

感官没有固定上限。多个感官若共同建立方向、危险、身体状态或行动条件，可以同时保留。
需要警惕的是按视觉、听觉、嗅觉、触觉、味觉依次扫描却没有新推断的“感官清单”。

### 诊断

- 细节可互换到任何人物身上：缺少注意力过滤。
- 细节很多，但人物没有据此行动或判断：装饰性堆积。
- 叙述先宣布结论，再补细节证明：推断空间被拿走。
- 每个细节都被解释：读者没有参与理解的余地。

## 2. 叙事时间分配

篇幅应追随叙事重要性，而不是钟表时长。先把材料分成三类：

### 前景场景 `foreground`

把不可逆决定、关键发现、拒绝、策略变化、关系移动和代价落到可经历的当下。读者需要
看到刺激出现、人物接收它以及回应形成，不能只读到事后结论。

### 简述 `compress`

压缩惯例、重复劳动、次要交流、旅行过程、已建立模式和只需说明结果的跨度。简述仍应有
选择：保留变化节点和少量代表性证据，不写成流水账。

### 省略或白空间 `omit`

跳过无新功能的连接、重复过程和无需展示的恢复期。场景切口前后各给一个清楚状态，
让读者能跨过空白；不要为了“完整”把每次移动、吃饭和寒暄都写出来。

### 决策程序

逐段问：

1. 这里是否发生读者必须亲历的发现或决定？是 → 前景。
2. 这里是否只说明一段时间内形成的模式或结果？是 → 简述。
3. 这里是否只连接两个已清楚的状态？是 → 省略。
4. 简述是否吞掉了人物真正改变策略的瞬间？是 → 把那个瞬间恢复为场景。
5. 场景是否只是把已知惯例逐步演一遍？是 → 压缩或跳过。

跨年、旅行和生产过程不必平均分配篇幅。可以用一个代表性片段建立模式，再用简述推进，
在不可逆变化处重新进入场景。

## 3. 行动—发现—回应

动作不是天然的叙事进展。搬东西、走路、点头、喝水若没有改变人物得到的信息、可选方案
或关系，只是舞台调度。

### 最小链条

```text
人物为目标采取行动
→ 遭遇阻力，或发现与预期不同的信息
→ 作出决定、拒绝、改变策略，或选择有代价的不行动
→ 局面留下可见变化
```

链条不要求激烈冲突，也不要求每场顿悟。早餐场景可以由一个没有被接过的碗、一项被回避
的安排和随后的座位变化成立；关键是回应改变了下一步，而不是音量有多大。

### 写作程序

1. 明确人物此刻想得到什么，而不是作者想交代什么。
2. 让第一个行动能够成功或失败，不写无方向的忙碌。
3. 阻力可以来自他人、制度、身体、时间、资源、误解或新事实。
4. 给人物接收阻力的瞬间；新信息不能穿过人物而毫无反应。
5. 回应必须具体：决定、拒绝、换策略、承担代价，或明确的有意不动。
6. 用 `turn.embodied_by` 的动作、物件或后果让转向可见。

`deliberate_inaction` 不是“什么也没写”。读者应看见人物有机会行动、意识到代价并选择
不动，以及这个选择如何改变关系、力量或后续约束。

### 诊断

- 动作很多，删掉后信息与局面不变：空转动作。
- 新信息出现，人物立刻换话题：缺接收与回应。
- 决定只由叙述者总结：转变没有被行动化。
- 结果来自巧合而非人物行动：因果链断开。

## 4. 对话是行动

对话的基本单位不是“信息句”，而是一个人试图通过语言从另一个人那里取得东西。可能是
答案、许可、承认、服从、安慰、距离、时间或掩护。

### 对话主导场景的五问

1. 每个人想通过说话得到什么？
2. 他用什么开局策略：直问、试探、讨好、威胁、玩笑、沉默或转移？
3. 对方怎样说“不”：拒绝、误解、回避、附加条件、反问、沉默或给出错误答案？
4. 哪一方在什么证据出现后改变策略？
5. 对话结束时，谁得到什么，又付出或暴露了什么？

“说不”不必出现“不”字。答非所问、过度解释、把问题改写成另一个问题，都可以形成
阻力。潜台词来自字面目标与真实目标的差，不来自每句话后面附一段心理解释。

### 直接、间接与概述

- 关键措辞本身会改变关系或决定：使用直接对话。
- 内容重要，但逐字表达不重要：使用间接转述。
- 已知惯例、重复问答、次要交流：使用概述。
- 关键发现藏在惯例交流中：先概述惯例，在异常处切回直接对话。

对话没有固定比例。一个独行场景可以没有台词；一场谈判可以大部分由台词构成。检查的是
策略和局面是否移动，而不是引号占了多少篇幅。

## 5. 视角与背景

视角契约包含六个相互约束的部分：

- 谁在叙述 `narrator`；
- 对谁叙述 `narratee`；
- 以什么文本形式叙述 `form`；
- 叙述离人物意识多近 `narrative_distance`；
- 哪些信息可知 `information_limit`；
- 人物会注意、忽略或误判什么 `attention_filter`。

默认形式也要自洽；只有非默认时才需要在 card 中显式填写 narrator、narratee、form。
信件、报告、日记、访谈或档案不是换一个排版就成立：选材、措辞、删改和遗漏都应受叙述
对象、记录目的和知识边界影响。

### 背景过滤程序

1. 先确定环境此刻对人物施加什么物理或社会限制。
2. 再确定人物因职业、经验、偏见、身体状态和欲望会先看到什么。
3. 只写足以支持行动和判断的空间关系；读者需要知道人物能否到达、隐藏、听见或逃离。
4. 允许误判，但必须来自人物已有经验，而不是作者故意扣住显而易见的信息。
5. 心理距离变化要有触发；不要在一句内从贴身感受跳到全知评论。

环境可以作为场景第一句，只要它立即完成定位、压力、行动条件或 POV 判断。应删除的是
可搬到任何章节的天气空镜，而不是环境本身。

## 6. 物件与主题纪律

物件先要在现实中可用。钥匙要开过门，杯子要被拿取，制服要造成行动限制；之后的重复、
损坏、易手、缺席或用途变化，才可能积累意义。

### 物件追踪

每次重要出现只记三件事：

1. 当前现实功能是什么？
2. 与上次相比发生了什么变化？
3. 哪个人注意到了这次变化，他是否理解其意义？

不要由叙述者宣布“它象征……”。让意义来自使用史、人物选择和出现位置。一次巧合不是
母题；反复出现也不自动等于象征。

### 主题发现

主题不是预先交给人物证明的论点。修改或章末回看时，记录：

- 人物反复做出的选择与付出的代价；
- 关系反复靠近、断裂或交换力量的方式；
- 物件和环境怎样随选择变化；
- 文本对预设主题压力提出了什么反例。

这些只能形成“文本目前在追问什么”的假设。保留反例，不把人物台词改成作者结论；只有
作者确认后，模式才可进入后续规划。

## Standalone 两轮自查

第一轮只看叙事呈现：

- 关键发现、决定、拒绝或关系变化是否被简述吞掉？
- 惯例和连接是否被扩成没有变化的完整场景？
- 行动、新信息与回应是否能连成链？
- 对话主导场景是否有目标、拒绝和策略变化？
- POV、形式、距离、信息边界和注意力是否一致？
- 重点细节是否提供推断或行动依据？

只修这些问题后，再进入第二轮，按 `anti-ai-patterns.md` 检查表层密度与 AI 成句。
两轮不要混做：结构性呈现问题不能靠换词解决，表层问题也不应借机重写人物动机。
