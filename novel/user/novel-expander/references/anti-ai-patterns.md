# 语言、密度与标点规则

本文件是 expander、auditor 与 ci 共用的语言规则入口；专项规则由下方链接的模块唯一维护。检查具体阅读问题，不把
“某模型必然这样写”或“人类绝不会这样写”当依据。词频控制与语义保真同时验收。

## 一、规则层次与使用顺序

1. 明确的作者要求、已确认的事实、知情边界与交付格式是约束。
2. 词频、句式、叙述重复是必须检查的质量项目。超线必须处理或给出具体保留依据。
3. 没有实际阅读问题的审美偏好不强改。保留有功能的重复、停顿和人物口头禅。

先读 `../../novel-ci/references/project-context.md`。按 `../../novel-auditor/references/language-tools.md`
运行扫描和复算，由 LLM 识别语义。不得凭子串次数直接替换，也不得以单句通顺免除整章密度检查。

本套流程用于中文小说。统一文风或使用已有作者规则／认可样稿时，读取
[文风与措辞一致性](../../novel-auditor/references/style-consistency.md)，按人物、叙述者和场景条件使用。
不要把所有声音拉到同一口吻；英文与学术写作不套用这里的中文小说规则。

同时检查空泛铺垫、无依据的拔高或权威、重复限定、生造标签和助手／草稿残留。
去 AI 味审查或发现这些现象时，读取 [Humanizer 小说补充](humanizer-fiction.md)。
它补充现有规则，不把人物的宣传、自我辩护、安慰和不可靠判断一律改成中性叙述。

## 二、词频与句式控制

### 2.1 通用关注词与项目档案

以下是扫描起点，不是语言来源鉴定：

- 连接与收束：与此同时、值得注意的是、毫无疑问、不言而喻、某种意义上、在这一刻、
  就在此时、事实上、显而易见、毋庸置疑、这一切、而这、或许、也许，这就是、在这个世界上。
- 情感套语：不禁、心中涌起、一股莫名的、内心深处、五味杂陈、百感交集、心头一震、
  眼中闪过一丝、嘴角微微上扬、嘴角勾起一抹。
- 泛化修饰：深邃、璀璨、凝重、肃穆、淡然、从容、不由自主、浑然不觉、恍若隔世、宛如。

项目在 `agent/audits/language-profile.json` 保存关注类别、形式、语义定义、阈值、适用范围、
样本版本和校准来源。模型与提示版本可以是观察背景，不是类别成立的证据。无档案也必须
扫描通用项，再由 LLM 从全文提名新出现的惯用词和句式，核对真实次数。

默认复核触发线：完整章中通用关注词达到 2 次；“不是 X，是 Y”及否定辨析变体超过 3 次；
破折号超过 15 处。它们是初始复核线，不是论文证明的文学定律。短片段不外推整章。
项目另有校准线时保存依据；不得为通过本轮修订临时提高阈值。

启用参考语料比较时，读取 `../../novel-auditor/references/style-reference.md`。参考分布与
扫描规则档案分开保存，任务内固定版本。它提供用词和局部聚集的证据，不把常见比例变成
配额。统计偏离结合上下文复核后可以保留；不为补足频率添词，不因参考中没有出现而禁用。
已有超线项仍按原流程处理，同一问题合并呈现证据。改动只服务语言表达，保留作者给定的
事件、动机、信息安排及叙事节奏；统计改善不能替代语义和人物口吻检查。

### 2.2 计数口径

原始命中、语义用途计数分别保留。每万字按同范围正文非空白字符计算，列出分母与原始次数。
同类别重叠命中去重，不同类别的次数不相加冒充总问题数。比较原稿、改稿和参考文本时，
范围、类别定义、分母算法与配置版本必须一致。参考频率不要求所有人物和场景逼近同一分布。

例如“方便”中的“便”不是连接用法；剩余“便”仍需读上下文，不得自动归为同一种习惯。
“保留”不从统计中扣除，只有词义分类改变对应类别归属。脚本只匹配、计数、定位和校验，
不建分词器、词性标注器或语义解析器；日常分类由 LLM 完成，不交还作者逐条处理。

### 2.3 密度必须形成处理结论

同时看段落/相邻段落、完整章、当前章加前两章。逐句都正确，也可能共同造成单调：
不断用同一动词扫视、以同一短语开头、凡事都“先……再……”、每个发言人都像同一份公文。
正式表达可合理存在，但不能给军事对白、报告或口头禅整类永久豁免。

每项超线必须是：修订后复算达标 / 具体位置及整体密度有据保留 / 未解决。
未解决或未检查不得报告通过。保留原因必须说明叙事或声音功能，不接受“这句中文没错”
作为对整章分布的回答。修后检查替代词与同功能句式，避免把一种口癖换成另一种。

### 2.4 句式与理解

连续同构排比、碎片、段尾判断、逐条补充、回忆后的今昔对照、孤立身体特写都要看功能。
读者是否能解码指代？评价是否重复已呈现的内容？特写是否让时间停顿有意义？
不能按固定数量强塞“消化句”，也不能一律把特写移到句中。段首重复先查辨识度与节奏，
不是一见两次“他”就换词。省掉冗余表达时保留否定、条件、量词、确定性及动作状态。

处理阅读负担或发现定语堆叠、主干延迟、名词串、指代困难与过度拆句时，读取
[中文阅读负担](../../novel-auditor/references/reading-load-zh.md)。按实际理解障碍和表达功能处理，
不设“的”的数量或句长上限；必要的术语重复、清楚的省略与有功能的长句可以保留。

## 三、统一标点

| 用途 | 固定形式 |
|---|---|
| 常用中文标点 | ，。；：？！、 |
| 外层引号 | “……” |
| 内层引号 | ‘……’ |
| 括号 | （） |
| 书名号与嵌套 | 《》、〈〉 |
| 破折号 | ——（两个 U+2014） |
| 省略号 | ……（两个 U+2026） |
| 外国人名间隔号 | · |

普通叙述、对白、界面文字引用不混用角引号、直引号、单根破折号、双连字符或英文点号省略号。
URL、代码、数据格式、小数、版本、型号及作者要求原样保留的引文按具体范围保护，并绑定
正文版本。不要全局 NFKC，不要盲目替换技术字符串，不接受整章“例外”。

检查符号字形、长度、顺序、配对和嵌套。跨段续引语要由 LLM 确认完整引用结构，不能仅凭
左右引号数量相等就通过。脚本发现的歧义应复核，不是假定无错。

字形规范化与节奏编辑分开：句号改逗号、合句、拆句、插入破折号会改变停顿和关系，须作
语义检查。连续短句可以合并，也可以保留有作用的重音；不能为了降密度把整段串成一口气。

## 四、声音、对话与信息

- 内心独白的口语程度随人物与叙述距离变化，不一律改成聊天语气。
- 不均匀节奏应来自叙事重要性，而非模拟“人类的不完美”。关键发现、拒绝和后果可展开，
  惯例与连接可压缩；安静场景也可承载关系、体验和认识。
- 对话标签只保留辨认说话人和有功能的行动，勿每句机械添加点头、微笑或心理解释。
- 犹豫、重复、答非所问和词不达意有时成立，但不刻意加错词制造自然感。
- 正式讨论说全对象、依据、条件和分工；已知方案只补新增部分。新听众的反应与协商有戏时
  保留现场，单纯传达旧内容才可概述。不要把所有新听众交流都压成一句。
- 读者可能见过谎话或误判，见过不等于知道真相。查询目标之前的索引并回到原文核对。
- 私下决定、对外宣布、执行、反悔可能是不同事件，不因提到同一决定两次就判重复。

## 五、描写与结构

感官数量没有固定上限。细节可帮助推断、行动、压力、时代/阶层定位或物件追踪。
功能重复项再删，不按数量判错。背景也可呈现 POV 的专业与偏见，不只负责推动动作。
比喻密度是检查线索，不是“一页一个”的失败阈值；看是否符合人物经验与当前判断。

留白、偏向与省略应来自视角和场景，不是漏写必要对象、条件或因果的借口。名称是否需要
补全看指称清晰度；有意匿名不强制命名。作者未确认的候选名字不得进入正典。

场景转换用项目约定的分隔方式；环境起笔应建立当前定位、压力、行动条件或体验。
章节结尾检查是否重复总结或空泛预告，修辞模板只是线索；不要宣称某句出现一次必毁全章。
章节价值按任务判断，不以“删掉仍能看懂主线”直接判失败，不强迫每章都有中段转向。

## 六、执行与验收

写前读有效项目约定、相关读者披露与语言档案。写后按作用范围计数、逐处分类、评估整体
密度、完成标点检查。诊断和授权修改分开；编辑用冻结原稿和最近接受稿验证实际差异。

完整章及连续窗口检查不能被短片段通过替代。连续审读按共享 project-context 协议：默认
最近十个发布章，每新增五个接受章或旧章实质修改时执行；三章计数不能替代它。

最终正文的标点、词频复算、语义回归和必要映射校验必须对应同一组哈希。任何再次编辑都
使相关结果失效。必验项未完成为 NEEDS_VERIFICATION；有确认问题则修订或明确报告未解决。
不为交付新版本而接受更差候选，也不以计数下降掩盖内容损伤。
