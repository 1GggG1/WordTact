## Module 1: genre_tests（通用类型契约）

### Purpose

检查场景是否满足 project_brief 声明的主类型读者期待，以及是否避免了该类型常见的廉价解法。

### Test items

1. 本场是否满足 primary genre 的读者期待？
2. 是否没有破坏题材基调（tone.avoid）？
3. 是否有符合类型的压力来源？
4. 是否避免了不属于该类型的廉价解决方案？
5. 是否保持类型承诺，而不是只借用外壳？

### Genre contract vs. surface

"类型外壳"指使用某类型的视觉元素/设定标签，但不提供该类型的核心体验。例如：悬疑类型的外壳是"有谜团"，但核心体验是"读者可以自己拼线索、猜真相"——如果所有线索只在最后一段由侦探口述，那就是只借了外壳。

### Severity guide

- **P1**: 类型核心承诺未兑现（如悬疑无解谜过程、浪漫无关系推进）；使用该类型明确禁止的廉价解法（如恐怖类型靠天降救援解决）。
- **RISK**: 类型元素存在但强度不足；tone.avoid 边界模糊。

### Example FAIL output

```yaml
genre_tests_result:
  status: FAIL
  failures:
    - severity: P1
      type: genre_breach
      location: {anchor: "角色 A 突然想起自己身上还有一件法宝", para: 30}
      issue: "project_brief.tone.avoid 含'机械降神式解决'——角色在绝境中突然想起未铺垫过的法宝，属于该类型读者最反感的廉价解。"
      evidence: "project_brief.genre.primary: '悬疑'；project_brief.tone.avoid: '机械降神式解决、靠运气脱险'。前文未出现该法宝的任何伏笔。"
      required_fix: "删除法宝解法；或在前文至少 2 处埋下该法宝的线索（角色 A 整理物品时/他人提及时），使解围有因果基础。"
  risks: []
```

## Module 2: Type extension packs

Each pack is loaded selectively based on `project_brief.genre.primary` and `genre.secondary`. Unmatched packs are skipped.

### horror（恐怖）

1. 是否存在不安全感？
2. 是否有未知、污染、侵入、失控或禁忌？
3. 是否避免过早解释恐怖来源？

**类型承诺**: 读者需要持续的不安感，而非跳跃惊吓（jump scare）。恐怖被解释清楚的那一刻就不再恐怖。廉价解 = 靠外界力量突然清除威胁。

### romance（浪漫）

1. 是否推动关系动态？
2. 是否存在欲望、误解、靠近或退缩？
3. 是否没有让角色直接说穿所有情绪？

**类型承诺**: 读者需要看到关系在两个独立个体之间的推拉中变化。廉价解 = 角色用对话直白说出"我爱你"代替关系推进；或靠外部事件（如第三人撮合）跳过情感发展。

### mystery（悬疑/推理）

1. 是否提供线索？
2. 是否隐藏关键信息但保持公平？
3. 是否避免侦探无根据神推理？

**类型承诺**: 读者需要能够参与解谜——线索必须在揭露前出现过。廉价解 = 侦探靠未展示的"观察力"直接得出结论；或关键信息在最后一刻才首次出现。

### political（权谋/政治）

1. 是否有权力结构？
2. 是否有利益冲突？
3. 是否有公开理由和真实理由的差异？

**类型承诺**: 读者需要看到权力博弈的过程——各方基于自身利益做选择。廉价解 = 对手犯蠢/降智让主角轻松获胜；或靠单一密谋解释所有事件。

### action（动作/战斗）

1. 行动是否清楚？
2. 空间关系是否可理解？
3. 代价是否存在？
4. 是否避免无后果爽感？

**类型承诺**: 读者需要能看到动作过程——在哪里、谁在动、打到什么程度。廉价解 = 空间关系模糊（"一场混战"一笔带过）；主角无伤通关；消耗无代价。

### xianxia（仙侠/修真）

1. 是否遵守世界观中已建立的修炼规则？
2. 能力提升是否有代价或前置条件？
3. 是否避免"突破全靠机缘巧合"？

**类型承诺**: 读者需要一个自洽的力量体系——强是有原因的。廉价解 = 临阵突破（除非该突破有贯穿前文的铺垫）；靠机缘跳过修炼逻辑。

### system（系统/游戏化）

1. 系统规则是否前后一致？
2. 是否避免系统在关键时刻"恰好"提供解决方案？
3. 角色是否通过自身选择而非系统指令推动剧情？

**类型承诺**: 系统是工具而非主角——角色仍需做选择。廉价解 = 系统在绝境时发布刚好能解围的任务/奖励；系统功能前后矛盾。

### urban（都市/现代）

1. 是否保持现实逻辑的底线（除非已声明超现实）？
2. 社会关系是否真实可感？
3. 是否避免了"全世界围着主角转"的叙事？

**类型承诺**: 即便有超现实元素，社会运行逻辑仍应是读者熟悉的。廉价解 = 靠权势/金钱简单粗暴碾压一切阻力；所有角色一见到主角就放下自身利益配合。
